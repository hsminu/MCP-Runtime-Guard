# MCP Guard UI 시안

`index.html`을 브라우저에서 열면 된다. 외부 라이브러리나 서버가 필요 없는 HTML/CSS/JavaScript 시안이다.

- 현황은 **활성 MCP 서버·승인 대기·차단된 호출 → 연결된 MCP 서버 → 지금 확인할 항목 → 최근 도구 호출 → 호출 흐름** 순서다. 요약 카드와 확인 항목을 누르면 관련 화면이나 필터로 이동한다.
- 전체 화면의 기본 본문·입력·버튼 글자를 14–15px 중심으로 확대하고 작은 보조 글자도 최소 12px로 표시한다. 현황의 서버 카드에는 `max_label`을 **공개 / 내부 / 기밀 + PUBLIC / INTERNAL / CONFIDENTIAL**로 표시하는 별도 색상 배지를 둔다. ‘보안 등급 · 최대 수신’과 신뢰 경계를 구분한다. 화면 폭에 따라 서버 카드는 4열·2열·1열로 바뀐다.
- 호출 로그는 전체 너비 목록이다. 행이나 도구 이름을 누르면 큰 상세 대화상자가 열리고, 호출 식별자·일시·서버·Task·경계·최초 판정·현재 상태·입출력 요약·처리 순서·구조화 메타데이터를 확인할 수 있다. 상세를 닫아도 목록 필터와 위치는 유지된다.
- 시간은 연·월·일과 시·분·초, 한국 시간(KST)으로 표시한다. CSV에는 시간대가 포함된 ISO 일시와 최초 판정·현재 상태·승인 상태를 별도로 내보낸다.
- 승인 대기열은 기본적으로 오래된 순이며, 검색·MCP 필터·정렬·페이지당 6건 표시를 지원한다. 30분 이상 대기는 별도 표식으로 구분한다. 대기와 처리 이력을 분리하고, 승인·거절 후 같은 페이지의 다음 대기 요청을 표시한다. 마지막 페이지가 비면 유효한 페이지로 이동한다.
- `대기 12건 추가 · 데모`로 요청 누적 상황을 확인할 수 있다. 추가 요청은 서로 다른 요청·호출·Task ID를 가지며 실제 전송은 없다. 설정의 초기화 또는 새로고침으로 복원한다.
- 대기 시간과 처리 시각의 시안 기준은 **2026년 10월 12일 14:35:00 KST**로 고정되어 있다. 단계별 시각·최초 판정 등 자료가 없는 항목은 미제공으로 표시한다.
- 상세 대화상자는 Escape·닫기·배경 클릭으로 닫힌다. 열려 있는 동안 배경 조작을 막고, Tab 포커스를 안에 유지하며 닫으면 이전 위치로 돌린다.
- MCP 서버 화면은 `server_id`, `transport`와 엔드포인트, `tier`·`max_label`, 등록 상태·세션, 등록 도구 수를 비교하는 표다. 이름·ID·엔드포인트 검색과 transport·등록 상태 필터를 지원한다.
- 서버 상세에는 연결 설정, 신뢰 경계, Registry·Connection·Scanner·도구 지문, 호출 로그에서 관측한 도구와 네임스페이스, 설정 JSON을 표시한다. ACTIVE는 등록 상태이며 실제 세션 연결을 뜻하지 않는다. 검사 일시·프로토콜 버전·스키마·지문은 수집되지 않았다고 표시한다.
- 서버 등록은 ID·표시 이름을 분리하고, `stdio`는 실행 파일 절대 경로·JSON 문자열 인자 배열·환경변수 이름 목록, `Streamable HTTP`는 전체 MCP 엔드포인트 URL을 입력한다. 전송 방식을 바꾸면 관련 입력란만 활성화하며, 이전 입력값은 보존한다. 등록 미리보기와 저장에는 선택한 방식의 필드만 포함한다.
- 신뢰 경계는 접속 방식과 독립적으로 지정한다. 외부 경계는 최대 INTERNAL이며, 내부 CONFIDENTIAL에서 외부로 바꾸면 INTERNAL로 조정하고 안내한다. 신규 등록은 PENDING(검토 대기)으로만 추가한다. 등록 형식 검사는 UI 시안 동작이며 실제 실행 파일·URL 신뢰·스캔·활성화 검증을 대체하지 않는다.
- 모든 항목은 합성 예시다. MCP 연결, Guard 판정, 승인 소비, 서버 검사, 저장소 쓰기 및 감사 기록은 실행하지 않는다. 새로고침하면 데모 상태가 초기화된다.

실제 제품 연결 시 UI는 확정된 bridge 이벤트만 표시해야 한다. 승인 만료·취소·무효화는 백엔드 이벤트로 처리해야 하며, 대기 시간이나 목록의 페이지 변경만으로 요청을 승인·삭제·만료시키지 않는다. 승인한 요청을 전송 성공으로 표시하지 않는다. 호출 상세와 CSV에도 문서 원문·인증정보·전체 전송 인자를 포함하지 않는다. 전체 인자는 승인 요청의 합성 사본 화면에서만 표시한다.

이 시안은 A 담당 GUI의 화면 흐름을 검토하기 위한 별도 파일이다. `docs/contracts.md`의 UI 명령·이벤트 계약을 확정한 뒤 PySide6 화면으로 옮기는 것을 전제로 한다.

## 2026-10-12 검증

- `node --check ui-preview/app.js` 문법 검사 성공.
- Node VM의 최소 DOM 대역으로 20개 동작 검사 성공: 배치 순서, 날짜/시간대 변환, 상세 창 생성과 목록 상태 보존, 검색·필터·정렬, 페이지 이동, 122건 누적, 승인·거절·취소·중복 처리, 이력·상태 동기화, 빈 결과, 초기화, HTML 이스케이프, CSV 일시/상태.
- 브라우저 도구가 `file://` URL 접근을 차단하여 실제 렌더링, 반응형 화면, 키보드 포커스의 브라우저 검증은 미실행이다. Node 검사는 이 항목을 대체하지 않는다.
- 실제 Guard 승인 소비·dispatch·wire·수신 부작용 검증은 백엔드 미연결로 검증 불가다.

### MCP 서버 목록·등록 상세 개선 검증

- `node --check ui-preview/app.js` 성공. 최소 DOM 대역의 Node VM에서 서버 화면 관련 20개 동작 검사 성공: ID·중복 검사, Windows/POSIX/UNC 절대 경로 형식, 인자 배열·환경변수 이름, HTTP URL, 전송 방식별 입력 전환·값 보존·설정 직렬화, 경계/등급 분리, 잘못된 제출의 무변경, PENDING 등록, 검색·필터·빈 결과, 상세·호출 로그 이동, HTML 이스케이프와 초기화.
- 실제 브라우저 렌더링·키보드 조작은 앞서 확인한 `file://` 도구 접근 제한으로 미실행. 실제 MCP 연결·프로세스 실행·Scanner·등록 상태 전이 검증도 미실행이다.
