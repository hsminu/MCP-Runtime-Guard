- SDK가 Exception이 아닌 `BaseException`을 내면 stderr에 traceback이 찍힐 수 있다. 넓은 예외 경계 추가가 필요해 설계 결정으로 남겼다.
- 쉬는 중 죽은 MCP 서버 감지, HTTP 실패 경로의 원격 세션 DELETE 누락, `pyproject`의 `guard-app` console script(`examples` 미포함) 실패는 이번에 고치지 않았다. console script는 패키징 담당 합의가 필요하다.
- 레포 `.venv`는 lock과 다르다. 아래 검증은 현재 `.venv` 기준이다.
