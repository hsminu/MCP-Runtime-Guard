## A20

### 모델 클라이언트와 승인된 실행 환경 연결

```text

목표: 선택된 제공자의 실제 API를 ModelClient 계약에 연결하고 승인되지 않은 환경의 민감 시나리오 시작을 막는 계약을 적용한다.
선행 조건: A06/A19, 명시된 모델 제공자·모드·허용 환경과 B/C의 T22 검증 계약. 미정이면 제공자 독립 변환/대역 검증까지만 진행한다.

연결: 설계 10.4절, I7·I9, T22. Task 간 격리는 A22에서 다룬다.
```

목표: 모델 제안을 Guard에만 제출하고 공개가 확정된 결과만 모델 대화와 UI로 보낸다.

검증: 모든 Guard 결과 분기, 대기→승인/거절, 커밋 실패의 Withheld, unknown 후 추가 모델 제안을 단위 테스트로 확인해. C의 T07/T08/T15/T35/T37을 실제 구현과 연결해.
