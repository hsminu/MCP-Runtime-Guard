## 한 일

- 표(`ui/call_logs.py`): 기본 열은 발생 시각 / 도구 · 서버 / 최초 판정 / 승인 상태 / 현재 상태다. 호출 ID는 "열 선택"에서 켜는 선택 열이다. 시각은 두 줄(월-일, 시:분:초), 전체 시각과 시간대는 상세에 둔다. 도구 이름을 굵게, 서버·종류를 그 아래 작게 둔다. `read`·`send` 같은 짧은 이름이 ID 때문에 잘리지 않는다.
- 세 단계를 따로 그린다. 최초 판정(허용·승인 필요·차단), 승인 상태(승인 불필요·승인 대기·승인 사용됨 등), 현재 상태(실행 중·완료·실패·결과 불명 등)를 모양·글자·색이 있는 알약으로 보인다.
- 52px 행, 고정 헤더, 헤더 경계를 끌어 열 너비 조절(직접 바꾼 너비는 유지), 선택 행 왼쪽 막대. 표가 좁으면 승인 상태 → 최초 판정 순으로 숨기고 툴팁으로 옮긴다.
- 상세는 옆 패널이다(창 폭 900px 미만이면 아래). 행을 클릭하거나 화살표·Enter로 고르면 150ms 뒤 상세를 묻고, 그 사이 이전 요청은 바로 무효가 된다. 패널은 단계별 상태·공개 사유·처리 순서·식별자(각각 복사 버튼)·전체 시각(KST)을 보인다. 인자·결과 원문은 없다.
- 필터: 검색, 서버, 상태, 기간. 서버는 Store 질의(`CallListQuery.server_id`, `store_views.call_list_query`가 `valid_server_filter`로 검사)로 보내고, 상태·기간은 B 질의에 필드가 없어 현재 페이지에만 적용하며 "상태·기간은 현재 페이지에만 적용됨"을 늘 보인다. 결과 수는 "n건 표시 · 받은 행 m건"이다. 불러오는 중·실패에는 0건을 보이지 않는다. 서버 목록은 등록 화면이 받은 서버 ID로 채운다(`window.py`).
- CSV: "표시된 k행 CSV 복사"로 실제 복사 범위를 버튼에 적고 2초 알림을 띄운다. 필드는 기존 `public_calls_csv` 그대로다.
- 로그 페이지는 바깥 스크롤 없이 표가 남은 높이를 채운다(`window.py`).
- 검수에서 고친 점: 행을 고르지 않았을 때도 빈 상세 패널이 360px를 차지해 1260px 창에서 승인 상태 열이 숨던 것을, 행을 고를 때만 패널을 열고(340px) 다섯 열 기준을 600px로 맞춰 고쳤다. 서버·상태 선택 상자가 3글자 폭까지 줄어 "모든 서ㅂ"처럼 잘리던 것을 가장 긴 항목 폭에 맞췄다.
