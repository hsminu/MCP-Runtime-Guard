# A49 · 로컬 파일 서버 폴더 등급 입력 폼

## 한 일

- `src/guard_app/ui/server_add.py`에 `LocalFolderRulesForm`을 추가했다. contracts 2026-10-15 결정("사용자가 등록할 때 루트 폴더와 하위 폴더별 등급을 정하고, 세그먼트 접두어 출처 규칙")에서 A가 맡은 등록 화면 입력 부분이다.
  - 루트 폴더 절대 경로를 입력받는다. 보이지 않는 문자, UNC·장치 경로, 상대 경로는 거부한다.
  - 하위 폴더 규칙은 여러 줄로 추가·삭제한다. 루트 기준 상대 경로를 `/`로 구분하고, 비워 두면 루트 전체 규칙이다. 각 규칙에는 등급(PUBLIC·INTERNAL·CONFIDENTIAL)을 고른다.
  - 다음은 거부한다: 역슬래시, 앞뒤 `/`, 빈 세그먼트, `.`·`..`, 보이지 않는 문자, 같은 접두어 중복, 등급 미선택, 규칙 0개.
  - 겹치는 규칙(예: `private`·`private/public`)은 허용한다. 판정은 B Catalog가 최고 등급으로 하고, 맞는 규칙이 없으면 미분류다. 안내문에 이 동작을 적었다.
  - 결과물은 `LocalFolderDraft(root, rules)`(`FolderLabelRule(prefix 세그먼트 튜플, label)`)다. 등록 레코드가 아니라 초안이다. 미리보기 Signal은 루트 경로 값을 숨긴다.
- 기존 `ServerAddForm`(일반 MCP 서버 초안)은 바꾸지 않았다. 앱이 제공하는 파일 서버의 실행값을 어떻게 등록하는지는 C2.11 서버와 C Registry에 달려 있어서, 이 폼에서 정하지 않는다.
- 하지 않은 것(미결): 서버 ID 즉시 안내(#20 6번), 검토된 설명 입력(#20 3번).
