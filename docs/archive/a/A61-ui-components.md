# A61 · 시안에 맞춘 Qt 컴포넌트와 실행 화면

## 한 일

- 기존 `ui-preview`의 흰색·연보라색, 선형 아이콘, 강조 버튼, 상태 배지를 실제 Qt 화면에 반영했다. 외부 이미지·웹폰트·추가 의존성을 사용하지 않는다.
- 실행·승인 검토·작업 제어를 별도 카드로 묶었다. 실행과 승인은 강조 버튼, 사본 확인은 보조 버튼, 긴급 차단은 위험 동작 테두리로 구분한다.
- 메뉴·브랜드·현황 카드 아이콘, 입력창·선택창·탭·표·스크롤바의 공통 스타일을 맞췄다. 선택창의 키보드·팝업 동작은 Qt를 그대로 사용한다.
- 600px 미만에서는 실행·승인·중지 버튼을 세로로 배치한다. 비활성화되는 버튼의 포커스를 읽기 전용 상세로 옮기는 기존 보호를 유지한다.
- 승인 사본의 일반 텍스트·전체 인자 표시, 중복 승인 차단, 취소·긴급 차단의 백엔드 확정 조건을 유지했다.

## A43 함께 정리한 범위

- UI 7개 파일의 Ruff 임시 예외(E501·S101·UP046)를 제거했다. Qt의 필수 camelCase 이름 예외는 유지한다.
- UI 10개 파일을 포맷하고 제외 목록에서 뺐다. 전체 포맷 제외 목록은 22개에서 12개로 줄었다.
- `RuntimePanel`에 타입을 붙이고 TaskProjection을 직접 좁혀 `union-attr` 억제를 없앴다. 이 모듈은 미타입 정의·호출도 검사한다.
- UI 밖의 기존 린트·타입·포맷 기준선은 남아 있다. `pyproject.toml` 변경은 main 대상 PR의 검토 대상이며 의존성·lock은 변경하지 않았다.

## 실제 검증

- 실행·승인·키보드·반응형·입력·표시 관련 기존 검사 181개 통과. 실제 합성 stdio/HTTP와 AGT real/mock 승인 경로 포함.
- 초기 배치 검사에서 사이드바 폭 때문에 900px의 카드 수가 달라지는 실패 2개를 확인하고 기존 폭으로 조정했다. 관련 반응형·현황 검사 21개 재통과.
- `ruff check src tests examples`, `ruff format --check src tests examples`, `mypy` 통과. mypy는 61개 소스 파일을 검사했다.
- `QT_QPA_PLATFORM=offscreen`으로 실제 합성 앱을 준비·승인 대기·사본 확인까지 실행해 캡처했다. Windows 글꼴을 명시적으로 로드한 렌더링에서 1260px·390px·320px을 확인했다. 320px 실행 화면의 가로 스크롤 최대값은 0이었다.
