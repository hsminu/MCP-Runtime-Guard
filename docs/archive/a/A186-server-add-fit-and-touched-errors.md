# A186 · 서버 추가 화면: 연결 방식별 빈 공간 없애기, 필수 입력 오류는 손댄 뒤에만

2026-10-30 · `claude/a-ui-ux-revamp-e419b9`(origin/main `0682a4d` 위, A185 다음). PR: 아직 없음(로컬 커밋).
관련: 사용자 UI·UX 전면 개선 요청 2절(연결 방식 전환 시 큰 빈 공간), 4절(필수 오류는 수정·제출 뒤). 등록 검사·명령 흐름은 바꾸지 않음.

## 원인

- 연결 방식 칸이 `QStackedWidget`이라 가장 큰 페이지(로컬 파일 서버 폴더 규칙) 높이를 늘 차지했다. stdio·HTTP로 바꿔도 그 높이가 빈칸으로 남았다.
- 검사 결과를 곧바로 빨간 오류로 보여서 화면을 열자마자 빈 필수 칸마다 오류가 떴다.

## 한 일

- `ui/server_add.py`의 연결 방식 칸을 A185의 `FitStack`으로 바꿔 현재 페이지 높이만 차지하게 했다. stdio 실행 파일 줄은 `ResponsiveRow`로 좁으면 세로로 놓는다.
- `_TouchedFields`를 더했다. 검사는 그대로 매번 하고, 오류 표시만 그 칸을 고치거나 포커스를 떠난 뒤, 또는 준비·저장을 누른 뒤에 한다. 붙여 넣기·재확인으로 채운 칸은 손댄 것으로 친다. 로컬 폴더 규칙의 경로·접두사·등급도 칸마다 따로 센다.
- 동작 줄에 "필수 입력·선택 n개를 확인하세요"를 보여 줘서 오류를 아직 띄우지 않은 상태에서도 준비 버튼이 왜 꺼졌는지 알 수 있게 했다.
- `scanner-desc` 세션이 붙일 Scanner 경고·설명 입력 자리는 건드리지 않았다(이 파일 변경을 커밋 하나로 따로 둠).
