# A121 · 화면 개편: 라이트·다크 색과 세션 작업 공간

2026-10-28. 데스크톱 화면이 "AI 채팅 앱처럼 보인다"는 사용자 의견에 따라 색·배치·문구 표시를 다시 잡았다. 기준은 Orca(stablyai/orca)와 Paradev(ParadevAI/Paradev)의 실제 소스 토큰이다. 보안 판정·승인 흐름과 B·C 계약은 바꾸지 않았다. 승인 검토·서버 목록 개편안은 별도 작업이다.

## 한 일

- **색(`ui/style.py`).**
  - 라이트는 Orca의 중립 회색 단계, 다크는 Paradev의 ember 테마를 따른다. 두 팔레트는 같은 역할 이름을 쓴다.
  - 주 동작은 두 테마 모두 잉크색이고, 선택 표시는 중립색이다. ember 강조색은 브랜드 표시와 지금 실행 중인 작업(실행 중 세션, 그 상태 알약, 스트리밍 답변)에만 쓴다.
  - 상태와 보안 등급은 색만으로 전하지 않고 항상 글자를 넣은 알약으로 보인다(개발문서 12.4).
  - 색 값은 팔레트에만 두고, 아이콘(`ui/icons.py`)도 팔레트 역할을 써서 테마를 바꾸면 다시 만들지 않고 따라 바뀐다.
- **배치(`ui/window.py`, `ui/sessions.py`, `ui/widgets.py`).**
  - 왼쪽 사이드바에 대화·결과 · 실행 활동·승인 대기·세션 목록·관리 화면을 두고, 사이드바 위에 테마 전환 버튼을 둔다.
  - 대화는 아바타 없이 작은 라벨로 화자를 표시하고, 사용자 입력은 테두리 있는 말풍선으로 보인다. 진행 중·중단된 답변은 라벨로 구분한다.
  - 세션 머리의 상태 알약은 Store가 확정한 상태를 한국어로 보인다.
  - 결과 · 실행 활동은 별도 화면으로 두고, 작업 취소·긴급 차단은 스크롤 아래에 고정한다. 대화 옆 패널 배치는 A122다.
- **현황·목록(`ui/overview.py`, `ui/servers.py`, `ui/call_logs.py`, `ui/approvals.py`).** 현황 지표는 아이콘·큰 숫자 카드 대신 한 줄 행으로 보인다. 활동 패널은 상자를 겹치지 않고 가는 선으로 구획을 나눈다.
- **감사 테스트(`tests/unit/test_ui_icons_style.py`).** 다음을 코드로 검사한다.
  - 라이트·다크가 같은 역할을 정의함
  - 색 리터럴이 팔레트 밖에 없음
  - ember 강조색은 허용 목록에만 쓰임
  - 상자 카드 수가 적고 활동 패널 안에서 겹치지 않음
  - 영문 작은 머리말과 자간이 없음
  - 간격이 4px 단위임

## 검증

- 새 테스트: `test_ui_icons_style.py` 8개, `test_ui_sessions.py`의 말풍선·라벨·테마 전환·상태 알약·결과 화면 고정 정지 버튼, `test_ui_overview.py`·`test_ui_keyboard.py`·`test_ui_responsive_detail.py` 보정.
- 합성 백엔드로 실제 창을 띄워 라이트·다크 화면을 오프스크린으로 캡처해 확인했다.
- 전체 테스트(`QT_QPA_PLATFORM=offscreen`, `tests` 전체): 4,874 통과, 4 skip, subtest 20. 실패 1개는 C 소유 `test_paths.py::test_app_root_is_under_local_app_data`이고 이 변경 전부터 실패했다. ruff check·format, mypy(strict)는 통과했다.

## 남은 것

- 승인 검토 창·서버 목록 개편은 제안 단계다. 일부는 C의 Registry·Scanner 투영과 활성화 API(C4.10), B 정책 변경(B3.10)이 필요하다.
- 실제 Windows 고DPI·화면 낭독기 확인은 하지 않았다(A36·A37 전체 GUI 인수, C).
