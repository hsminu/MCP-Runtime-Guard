# A122 · 결과 · 실행 활동을 옆 패널과 전체 화면으로 나눔

2026-10-28. 사용자 결정: 대화 머리의 "활동"은 대화 옆에 패널로 열고, 왼쪽 사이드바의 "결과 · 실행 활동"을 누를 때만 전체 화면을 채운다.

## 한 일

- **한 덩어리를 두 자리로 옮김(`ui/window.py`).**
  - 선택한 세션의 Task 상태·실행 컨트롤·승인 검토와 아래 고정된 작업 제어를 한 위젯(`activityContent`)으로 묶었다.
  - 이 위젯을 대화 옆 패널(폭 376px)과 결과 화면 사이에서 옮긴다. 같은 위젯이라 상태가 둘로 갈라지지 않는다.
- **열고 닫기.**
  - "활동"을 누르면 대화 화면에 머문 채 옆 패널이 열리고, 다시 누르거나 패널의 닫기 버튼을 누르면 닫힌다.
  - 패널이 열려 있으면 모든 세션 머리의 "활동" 버튼을 선택 상태로 표시한다(`ui/sessions.py`의 `set_activity_open`).
  - 사이드바에서 결과 화면으로 가면 위젯이 전체 화면으로 옮겨 가고, 대화로 돌아오면 패널로 돌아온다.
  - 옆 패널에서는 화면 제목을 숨기고 폭 제한을 푼다. 전체 화면에서는 제목과 808px 폭 제한을 둔다.
- **좁은 창.** 폭 900px 미만 또는 높이 700px 미만이면 패널을 둘 자리가 없어서 "활동"이 결과 화면을 연다.
- 패널 머리·구분선 스타일 3줄을 `ui/style.py`에 추가했다.

## 검증

- `test_ui_sessions.py`:
  - `test_activity_button_docks_results_beside_the_conversation`: 1280×800에서 패널 열림·버튼 선택 표시·제목 숨김·정지 버튼이 스크롤 밖에 있음·사이드바 전환 후 복귀·두 가지 닫기
  - `test_compact_activity_button_opens_the_results_page`: 320×400에서 결과 화면으로 이동
  - `test_sidebar_results_open_a_full_page_with_the_selected_session_in_scope`: 사이드바 진입 시 전체 화면, 돌아오면 패널 닫힘
- 합성 백엔드로 실제 창을 띄워 패널을 연 화면을 라이트·다크로 캡처해 확인했다.
- 전체 테스트(`QT_QPA_PLATFORM=offscreen`, `tests` 전체): 4,874 통과, 4 skip, subtest 20. 실패 1개는 C 소유 `test_paths.py::test_app_root_is_under_local_app_data`이고 이 변경 전부터 실패했다.

## 남은 것

- Task가 없는 초안 세션에서는 "활동" 버튼이 꺼져 있다. 표시할 Task가 없어서이고, 원래 동작이다.
- 패널 폭은 고정이다. 사용자가 끌어서 바꾸는 기능은 없다.
