# A213 · 채팅 답변 머리글에서 "(검증되지 않은 내용)" 지우기

2026-10-30 · `wip/next` · PR #110. 출처: 사용자 요청("ai 답변 위에 검증되지않은 답변은 좀 지우자").

## 한 일

- `session_transcript.py`의 채팅 답변 머리글 두 개에서 "(검증되지 않은 내용)"을 지웠다.
  - `ANSWER_LABEL`: "Guard · 모델 답변"
  - `PARTIAL_ANSWER_LABEL`: "Guard · 모델 답변 작성 중"
- 그대로 둔 것
  - `STOPPED_ANSWER_LABEL` "Guard · 모델 답변 중단됨 (완료되지 않은 내용)": 중단 상태를 알리는 문구라 남겼다.
  - 답변 본문은 지금처럼 일반 텍스트로만 그린다(T18). 머리글 문구만 바뀌었다.
  - 대화 영역의 접근성 이름("세션 대화 · 검증되지 않은 모델 답변은 일반 텍스트로 표시")은 화면에 보이지 않아 그대로다.
  - 도구 설정의 "서버 제공 이름 · 검증되지 않은 내용", 승인·검사 화면의 `UNVERIFIED_NOTICE`는 다른 화면이라 건드리지 않았다.
- 세 머리글은 같음 비교로만 쓰이고 서로 다르다. 접두어 비교는 없다.
- `test_ui_sessions.py`의 기대값 세 곳을 새 문구로 바꿨다.
- 설계 문서·계약에 채팅 답변 머리글의 미검증 표시를 요구하는 규칙은 없다.
