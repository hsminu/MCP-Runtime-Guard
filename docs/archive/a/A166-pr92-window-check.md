관련: A163, A33–A35, B6-05, I5·I9, T18/S05.

## 확인 방법

- 실제 SQLite Store를 쓰고, 행은 SQL로 직접 넣었다. 넣은 행은 다음과 같다.
  - Task 2개, 요청 120개(서버 `docs`·`drive`)
  - PENDING 승인 2개와 그 요청: 하나는 7분 전 만료, 하나는 4분 뒤 만료
  - 감사 이벤트
- 제품 `BackendBridge`와 `BackendBindings(queries=store)`를 거쳐 `GuardWindow`의 호출 로그·승인 목록이 이 Store를 조회했다(StoreQueryLink). 세션 제어는 대역이다.
- 서버 목록 행은 `REG_LIST` 응답으로 직접 넣었다: 정상, `REG_SETTINGS_MISMATCH`, `URL_NOT_CANONICAL`, 설정 파일에 없음.
- 창 1280×860을 두 번 띄워 `QWidget.grab`으로 찍었다.
  - offscreen(글꼴 `C:/Windows/Fonts`)
  - 실제 Windows 플랫폼: 저장된 이미지가 1280×860이라 이 PC 화면 배율은 1.0이다.
- 넣은 판정·상태 조합은 합성 값이다. 화면이 Store 값을 그대로 옮기는지만 본다.

## 결과

- 호출 로그
  - 첫 페이지 "전체 122건 · 현재 페이지 50건", "1 / 3"이다. 이전 버튼은 꺼져 있다.
  - 다음을 누르면 "2 / 3", 50행이 나온다(`req-070`부터).
  - "drive"를 입력하고 Enter(또는 포커스 이동)로 보내면 "전체 42건", "1 / 1"이다. 이전·다음 버튼은 모두 꺼져 있다. 검색은 입력 중에는 보내지 않는다.
- 승인 목록
  - 만료가 지난 `appr-old`는 "승인 대기 · 승인 유효 시간 지남 · 상태 다시 확인(참고)"이다.
  - 만료 전인 `appr-new`는 "승인 대기"다.
  - 시각은 KST로 나온다.
- 서버 목록·상세
  - `drive`(설정 불일치)와 `remote`(URL 거부)는 목록에 "등록 검토 중 · 설정 확인 필요"로 나온다.
  - `drive` 상세의 설정 확인 줄은 "설정 파일과 등록 내용이 다름. 이 서버의 도구는 숨겨짐."이다.
  - 설정 파일에 없는 행은 A165 표시대로다.

## 찾아서 고친 것

호출 로그와 승인 목록의 건수 줄이 실제 글꼴에서 "전체 122건 · 현재 / 페이지 50건"처럼 구절 중간에서 끊겼다.

- 원인: 단어 줄바꿈 라벨 뒤에 늘어나는 빈칸(`addStretch`)이 있었다. 라벨은 줄바꿈 기준 크기 힌트(85px)만 받았다. 문장 폭은 147px이다.
  - 글꼴이 없는 offscreen에서는 힌트가 문장 폭과 같아 드러나지 않았다.
- 고침(`ui/call_logs.py`, `ui/approvals.py`): 빈칸을 빼고 라벨에 늘림 비율 1을 줬다. 승인 목록의 좁은 화면(세로 배치) 시험도 그대로 통과한다.
- 시험 `test_ui_approvals.py::test_page_counts_stay_on_one_line_beside_the_pager_buttons`: 두 화면 모두 라벨이 크기 힌트보다 넓고 문장이 한 줄에 들어가는지 본다.
  - 두 고침을 하나씩 되돌리면 글꼴이 있을 때와 없을 때 모두 이 시험이 실패했다. 매번 원래 바이트로 되돌린 뒤 SHA-256 일치를 확인했다.
- 실제 Windows 창에서 다시 찍어 한 줄로 나오는 것을 확인했다.
