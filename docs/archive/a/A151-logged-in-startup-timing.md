# A151 · 로그인한 CODEX_HOME의 실제 시작·정리 시간

2026-10-29 · A · 관련 I6·I9·I11, T22·T39·T40, 개발문서 10.4·12절. 계약·C 구현 변경 없음.

## 측정 조건

실제 Windows 데스크톱 제품 `main()`과 고정 Codex 0.162.1을 실행했다. Python 3.12.15, PySide6 6.12.0이다. [A161](A161-msix-l2-path-observation.md)의 MSIX 경로 비교 실패 때문에 기존 `CodexProcessPreparation(root=app_root().resolve())` 설정으로 같은 물리 앱 폴더를 지정했다. L2·launcher·모델·계정 응답은 실제 구현 그대로다.

시작은 `main_begin`→bridge READY, L2는 `run_l2` 진입→반환, 종료는 bridge CLOSING→`main_end`의 `perf_counter()` 차이다. Python import와 관찰기 초기화는 시작 시간에서 제외하고 관찰 JSON 저장 비용은 포함한다. 프로세스 생성부터 창이 그려질 때까지의 시간은 아니다. 개별 관찰값이며 성능 보장·백분위 통계가 아니다.

## 실제 결과

| 실행 | 시작 시 저장된 로그인 | 시작(초) | L2(초) | 종료(초) | 종료 직전 상태 |
| --- | --- | ---: | ---: | ---: | --- |
| API 키 1 | 유효 API 키 | 7.094353 | 5.409826 | 0.215173 | 같은 실행에서 로그아웃·틀린 API 키 로그인 후 종료 |
| ChatGPT 1 | 브라우저 로그인 | 4.068275 | 3.019705 | 0.232217 | CHATGPT 유지 |
| ChatGPT 2 | 브라우저 로그인 | 4.084284 | 3.129931 | 0.240598 | 실제 로그아웃·SIGNED_OUT 재조회 후 종료 |

- 세 실행 모두 L2 통과, main 반환 0, 종료 시 Task 폴더 0개다. 관찰된 모든 Codex PID는 종료 확인 True·returncode 0과 짝이 맞는다.
- ChatGPT 1은 계정 조회 프로세스를 연 상태에서 앱을 닫았다. 로그인 암호문과 primary 자격증명은 유지됐으며 다음 실행에서 CHATGPT가 확인됐다.
- 실제 로그아웃 시작→자격증명 정리 완료는 유효 API 키 8.990540초, ChatGPT 6.064340초였다. 정리 함수 구간은 각각 0.008911초·0.006042초였다. RPC·프로세스 종료 대기도 전체 로그아웃 시간에 포함했다.
- 진행 중 안내에서 ChatGPT 1의 READY 절대 계측값 4.99초를 시작 시간으로 말했다가, 최종 계산에서 `main_begin`을 빼 4.068275초로 바로잡았다.

## 근거와 남은 것

- [완료된 시간·프로세스·계정 관찰 JSON](../evidence/A109-A151-A52-real-login.json). API 키 기본 경로 실패 두 회는 [A161](A161-msix-l2-path-observation.md)에 별도 기록했다.
- 기본 제품 경로의 L2 성공은 확인하지 못했다. 사용자가 C 수정 보류를 선택했으므로 C의 정규 경로 비교 수정·다른 파일 거부 회귀·기본 제품 재인수는 남아 있다.
- 독립 하위 에이전트가 안전한 JSON과 정리 순서를 읽기 전용으로 검토했다. C 소유자의 인수 승인이나 T43 전체 통과가 아니다.
- 이번 후속은 실제 측정·문서 기록만 했고 제품 코드 추가 변경은 없다.
