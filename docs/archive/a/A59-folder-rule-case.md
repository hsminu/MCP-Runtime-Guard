# A59 · 폴더 등급 규칙 중복을 대소문자 무시로 검사

A49 폴더 등급 폼을 다시 손본 작업이다. A49 기록은 고치지 않는다.

## 한 일

- Windows 폴더 이름은 대소문자를 구분하지 않는다. 그런데 `Docs/Private`와 `docs/private`가 서로 다른 규칙으로 통과해, 같은 폴더에 서로 다른 등급을 입력할 수 있었다.
- `LocalFolderRulesForm`이 세그먼트를 `casefold()`한 키로 중복을 비교하도록 바꿨다. 오류 문구에 대소문자만 다른 이름도 같은 폴더라고 적었다.
- 저장되는 접두어는 입력한 그대로다. 실제 경로의 대소문자 처리는 C `safe_path`(C2.3)가 정한다.

## 실제 검증

- `tests/unit/test_server_add_folders.py` 17개 통과. 대소문자만 다른 규칙을 거부하는 테스트 1개를 추가했다.
- `ruff check`·`mypy` 통과. 이 파일은 pyproject의 포맷 제외 목록에 있다.

## 남은 한계

- 대소문자 외의 같은 폴더 표현(끝 공백·점, 8.3 짧은 이름)은 C `safe_path`의 몫이라 여기서 다루지 않는다.
