# A128 · MCP 서버 추가: 설정 붙여넣기와 입력 줄이기

2026-10-28. 사용자 의견: "MCP 추가 초안"에서 '초안'을 빼고, 사용자가 덜 적고 추가할 수 있어야 한다. `ui/server_add.py`의 추가 화면을 고쳤다. Registry 등록은 아직 연결되지 않아 이 화면은 여전히 입력 형식만 확인한다. 화면 문구로 그 사실을 밝힌다.

## 한 일

- **이름.** 메뉴·제목·버튼에서 '초안'을 뺐다. 메뉴는 "MCP 서버 추가", 버튼은 "입력 확인"이다. 상태 문구는 "Registry 등록은 아직 연결되지 않아 여기서는 입력 형식만 확인함."과 "입력 확인 완료 · Registry에 등록되지 않음."이다.
- **설정 붙여넣기.**
  - 붙여 넣고 "칸 채우기"를 누르면 칸을 채우고 붙여넣기 상자를 바로 비운다(`read_pasted_server`).
  - 읽는 형식: Claude·VS Code 설정 JSON(`mcpServers`·`mcp_servers`·`servers` 또는 항목 하나), Codex `config.toml`의 `[mcp_servers.이름]`, http(s) URL, 실행 명령 한 줄.
  - 환경변수는 이름만 가져온다. 값과 HTTP 헤더는 버리고 버린 개수만 알린다. 서버가 여럿이면 첫 서버만 채우고 나머지 개수를 알린다.
  - 신뢰 경계·최대 수신 등급은 붙여 넣은 내용으로 정하지 않는다. 사용자가 직접 고른다(등급·경계를 외부 입력에서 신뢰하지 않음).
  - 읽지 못하면 상자를 그대로 두고 고정 문구로 이유를 알린다(빈 입력, JSON 형식, 서버 항목 없음, 인자 형식, 닫히지 않은 따옴표).
- **입력 줄이기.**
  - 표시 이름을 맨 앞에 두고 비워도 되게 했다. 비우면 서버 ID를 쓴다.
  - 표시 이름을 영문으로 쓰면 서버 ID를 자동으로 채운다(`suggested_server_id`, bridge의 `valid_server_id`를 통과한 값만, A54). 사용자가 ID를 직접 고치면 더 덮어쓰지 않는다.
  - 실행 파일은 "찾아보기"(`.exe` 필터)로 고를 수 있다.
  - 인자는 명령줄처럼 쓴다(`serve --root "C:\My Docs"`). `[`로 시작하면 기존 JSON 배열로 읽는다. 길이·개수 상한은 그대로다.
  - 환경변수 이름은 줄바꿈 외에 쉼표로도 나눈다.
  - 로컬 파일 서버 폴더 등급 칸은 접어 두고 링크 버튼으로 펼친다.
- **실행 파일 검사.** EXE-01(2026-10-27 결정)과 C launcher에 맞춰 절대 경로의 `.exe`만 통과시킨다. `.cmd`·`.bat`은 실제 실행 파일(node.exe 등)을 고르고 스크립트는 인자에 넣으라고 안내한다.

- 새 테스트(`tests/unit/test_server_add.py`):

  - 인자 명령줄 읽기와 닫히지 않은 따옴표
  - 표시 이름 생략·ID 추천(한글 이름은 추천하지 않음)
  - `.exe`만 통과(`.cmd`·`.bat`·`.py` 거부)
  - 찾아보기 선택·취소
  - 폴더 등급 칸 접기·펼치기
- 보정: `test_ui_keyboard.py`(새 탭 순서, 표시 이름 → 서버 ID 자동 채움 → 찾아보기), `test_ui_responsive_detail.py`·`test_ui_sessions.py`(`.exe` 명령, 접힌 폴더 칸), `test_ui_overview.py`(메뉴 이름·미연결 문구).
