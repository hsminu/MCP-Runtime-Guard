# A127 · 현황 화면을 줄 목록으로 줄임

2026-10-28. 사용자 의견: MCP 현황 화면에 옛 디자인의 흔적이 남아 있고, 아래로 너무 길어 읽기 힘들다. A121의 색·간격 기준에 맞춰 현황 화면(`ui/overview.py`)을 다시 짰다. 보여 주는 데이터와 조회 연결 여부 표시는 바꾸지 않았다.

## 한 일

- **옛 흔적 제거.**
  - 서버·확인 항목·최근 호출이 각자 테두리 카드였던 것을 테두리 상자 하나 안의 얇은 선 목록(`RowList`·`ListRow`)으로 바꿨다. 지표 목록과 같은 모양이다.
  - 라벨·값을 세로로 쌓던 칸을 한 줄 요약(`ID · 신뢰 경계 · 등록 · 세션 · 연결 방식`)으로 바꿨다.
  - 베이지 등급 상자 대신 작은 알약(`LabelPill`, "최대 수신 내부")을 쓴다. 영문 코드는 툴팁·접근성 이름에 남긴다. 서버 상세 화면의 `SecurityLabel`은 그대로다.
  - 시간대별 호출 카드 12개와 진행 막대를 막대그래프 하나(`FlowChart`)로 바꿨다. 막대마다 툴팁으로 시간·건수를 보이고, 접근성 설명에 요약을 넣는다. 색은 팔레트 역할(`mute`, `hairline_strong`)만 쓴다.
  - 확인 항목으로 가는 바로가기 상자와 상자 모양 이전·다음 버튼을 링크 버튼으로 바꿨다.
- **길이.**
  - 순서는 지표, 지금 확인할 항목(5개씩 넘김), 연결된 서버(5개까지, 전체 목록 링크), 최근 호출, 호출 흐름이다.
  - 창 폭에 따라 열 수를 바꾸던 서버 격자를 없앴다. 폭이 바뀌어도 같은 행 객체가 남아 키보드 초점이 유지된다.
  - 목록 시간은 `format_kst_short`("10월 28일 15:37")로 줄였다. 집계 기준 시각은 전체 형식을 유지한다.
  - 시연 데이터, 폭 1280px 기준으로 페이지 높이가 5075px에서 1673px가 됐다(오프스크린 측정).

## 검증

- 테스트 보정·추가:
  - `tests/unit/test_ui_overview.py`: 확인 항목이 먼저 오고 서버는 폭과 상관없이 5개, 좁아져도 서버 행 초점 유지, 넘김 버튼, 연결된 서버 한 줄 요약
  - `test_ui_display_escaping.py`·`test_ui_approval_t18.py`: 새 행 클래스 이름으로 비신뢰 텍스트 표시·승인 필드 검사 유지
  - `test_ui_icons_style.py`: 상자 카드 허용 목록이 `placeholderCard`·`metricList`·`rowList`
- 라이트·다크 창과 전체 페이지를 시연 데이터로 오프스크린 캡처해 확인했다.
- 전체 테스트·정적 검사 결과는 A128과 같은 실행이다.

## 남은 것

- 현황 데이터는 여전히 주입형 조회다. 실제 Registry·감사 조회 연결은 A28–A32·A35에 남아 있다.
- 실제 Windows 고DPI·화면 낭독기 확인은 하지 않았다(A36·A37, C).
