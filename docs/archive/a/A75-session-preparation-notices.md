# A75 · 구성 검증·준비 실패·정리 미확인 안내

2026-10-18. A 내부 구성 검증/자원 준비 연결부의 고정 오류를 새 세션 초안과 기존 Task 화면에서 구분하도록 했다. 구성 검증 미준비, 구성 불일치, 준비 실패, 종료·정리 미확인 안내를 공통 표시 함수에 모았고, 알려지지 않은 코드·예외 원문·경로는 출력하지 않는다.

정리 미확인 상태는 terminal Task에서도 우선 표시하고 목록에 “정리 완료 미확인”을 표시한다. 성공한 종료나 미실행이라고 단정하지 않는다. 실패 상태에서는 보내기를 비활성화하며 다른 Task의 입력·선택·안내는 유지한다. 생성 요청이 끝나면 요청 중 안내를 교체하고, `SESSION_CREATION_UNAVAILABLE`와 결과 미확인인 `SESSION_CREATION_UNCONFIRMED`를 구분한다.

검증: `test_ui_sessions.py` **35 통과**. 인접 runtime/model settings까지 포함한 검사 **60 통과·기존 경고 5개** 후 마지막 목록 문구 보정을 UI 35개로 재검증했다. Ruff·format 3파일, mypy 2소스 통과. offscreen GUI의 한글 렌더링도 직접 확인했다.

회귀는 초안 유지, 실패 뒤 요청 중 안내 잔류 방지, 다른 Task 오염 방지, 늦은 생성 완료 거부, raw 경로/오류 미노출, 정리 미확인 표시를 검증한다. 관련 I6·I7·I9이며 Store 상태나 B 정지 의미는 바꾸지 않는다. 주입 이벤트 GUI 근거는 ignored `.test-artifacts/a72-ui/`에 있다. 실제 C 프로세스·파일 정리 인수는 아니다. UI와 A 소유 단위 테스트만 변경했고 PR은 생성하지 않았다.
