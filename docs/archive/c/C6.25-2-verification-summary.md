## 다른 담당 작업의 C 독립 확인(리뷰 프로브)

C6.25에 적은 것(B6.13, #69, #70, C4.19·C4.20)에 더해 이번 기간에 한 것이다. 프로브는 저장소에 넣지 않은 임시 시험이고, 결과는 각 PR의 C 리뷰 댓글에 있다.

- **#83 A151 제품 시작 L2(실제 codex.exe):** `CodexProcessPreparation` 시작 3회 모두 통과, 회당 1.44–1.55초. 1초에 취소하면 1.29초에 정리, 매 회 뒤 남은 codex.exe·Task 폴더 0. 로그인 없는 CODEX_HOME, 한 PC 측정이다.
- **#83 C5.6 실패 원인:** Store `halt_execution` 호출 위치를 추적해 `GuardService.aclose()` → 전역 정지임을 확인했다. 같은 회차 재조립을 앱 재시작으로 바꿨다(#85). B가 의도한 동작으로 답했고, 정상 종료 사유는 #89 `GUARD_CLOSED`로 나뉜다.
- **#83 등록·URL:** 닫힌 포트의 HTTP 서버와 바로 끝나는 stdio 서버로 목록 수집을 돌리면 `DispatchError`가 등록 명령 밖으로 나가 "결과 미확인"이 됐다. A157이 시작 실패를 `REG_SERVER_UNREACHABLE`로 바꿨다. 설정 URL이 C2.5에 걸리면 조립 전체가 실패하던 것도 그 서버만 격리하게 됐다.
  - 남은 것: 바로 끝나는 stdio 서버는 여전히 `SessionCloseFailed`로 제품 시작 전체를 실패시킨다(A158).
- **#86 C3.8 조건 6(조회와 계수 대조):** `c_counting`으로 T01·T02(오래된 revision 승인 거부 뒤 승인)·T03·응답 유실을 stdio·HTTP에서 돌린 뒤 B6.16 조회(`list_calls`·`get_call`·`list_approvals`)를 요청마다 C 계수와 맞췄다.
  - 요청 7개 불일치 0. 오래된 revision 승인은 `APPROVAL_RACE`·계수 0이었다.
  - 결과 불명에도 `COMMITTED` 단계가 붙는 것과, Task를 지정하지 않은 목록에서 같은 판정 시각이면 순서가 바뀌는 것(8회 중 2회)을 B에 알렸다.
- **#83+#86 URL 문제 서버:** 두 PR을 합친 코드에서 B3.15가 서버를 숨겨도 A 조립이 그 URL을 다시 검사해 시작 전체가 실패하는 것을 찾았다. A157 뒤에는 그 서버만 실패한다.
- **#87 A49 실제 C 파일 서버:** 등록 명령(실제 목록 수집) → 활성화 → 제품 조립(C launcher·지문) → Guard 순서로 돌렸다. 루트 PUBLIC, 하위 폴더 CONFIDENTIAL 설정이다.

  | 요청 경로 | 결과 | Task 등급 | dispatch |
  | --- | --- | --- | --- |
  | 기밀 폴더 파일(정확한 이름) | 공개 | CONFIDENTIAL | 1 |
  | 대소문자 바꿈 | 공개 | CONFIDENTIAL | 1 |
  | 8.3 짧은 이름(`SECRET~1`) | 공개 | CONFIDENTIAL | 1 |
  | 루트 파일 | 공개 | PUBLIC | 1 |
  | `../`·루트 안 정션·루트 밖 절대 경로 | `INVALID_ARGUMENTS` 거부 | PUBLIC | 0 |

  대소문자·짧은 이름으로 등급을 낮출 수 없다. C `resource_id`가 디스크의 실제 이름을 돌려주고, 출처 규칙도 실제 이름으로 저장되기 때문이다.
- **#87 A155 재시작:** Registry ACTIVE·종류 OTHER에서 설정만 READ/SEND로 바꾸고 `request_review` 뒤 명시 시작으로 제품 조립을 했다.
  - 조립 성공, `observe`가 종류를 기록, 상태 PENDING. 그 상태의 SEND는 `REG_NOT_ACTIVE`·dispatch 0
  - 다시 활성화하고 재시작하면 SEND 공개·dispatch 1
- **#89 B6.9 승인 원자화:** C3.5 조건 1–3(생성·종결 한 트랜잭션, 관계·epoch·revision 조건부 갱신과 행 수 1, 결과 구분)을 코드로 확인했다. 조건 4(C 독립 결함 주입)는 제출 뒤에 한다.
