# C6.30 · Codex 설치 스크립트 출력·내려받기 경계, C-CODEX-02·03 상태 (#124 C 몫)

관련: [#124](https://github.com/hsminu/MCP-Runtime-Guard/issues/124) 3번·4번 C 항목, C6.13(설치 스크립트), A220(Sparrow 04.01), C-CODEX-02·03.

## 문제

B가 main `27d70f3` 검수(#124)에서 C 몫으로 둘을 짚었다.

1. **`tools/install_codex.py`**
   - 실패 때 `print(f"설치 실패: {error}", file=sys.stderr)`로 잡은 오류를 그대로 출력했다. A220이 `__main__.py`에서 고친 Sparrow 04.01과 같은 모양이다. 오류는 고정 코드라 실제 노출은 없지만, 검사 범위에 `tools/`가 들어가면 걸릴 수 있다.
   - 내려받기 크기 상한과 리다이렉트 대상 확인이 없었다. 내용은 sha512 무결성이 지켰다.
2. **관리대장 C-CODEX-02·03(높음)**: 상태가 "발견·조치 결정"이라 미조치로 읽혔다.

## 수정

1. **실패 출력**
   - 잡은 오류를 `print`하지 않는다. A220처럼 `guard_app.install_codex` 로거로 한 줄만 지금의 stderr에 낸다.
   - 내보내는 것은 `failure_code(error)`다. 인자 하나가 대문자 코드 모양(`[A-Z][A-Z0-9_]{0,63}`)일 때만 그 코드이고, 아니면 `CODEX_INSTALL_FAILED`다.
   - 성공 줄(`codex <버전> 설치 확인: <경로>`)은 오류가 아니라 그대로 둔다.
2. **내려받기**
   - 처음 주소: `is_registry_url`로 https·호스트 `registry.npmjs.org`·사용자 정보 없음·기본 포트를 본다. 이전 접두어 검사도 같은 주소를 막았고, 이번에는 리다이렉트에 같은 판정을 쓰려고 함수로 뺐다.
   - 리다이렉트: `_RegistryOnlyRedirect`가 같은 레지스트리 https 주소로만 따른다. 아니면 `CODEX_INSTALL_REDIRECT_REJECTED`다.
   - 크기: `_MAX_TARBALL_BYTES` 1 GiB다. `codex.exe` 자체가 약 318 MiB이고 tarball은 그 압축본이라 정상 설치를 막지 않는다. 선언 길이가 크면 쓰기 전에, 본문이 넘치면 쓰다가 멈춘다(`CODEX_INSTALL_TOO_LARGE`). 이 함수가 만든 부분 파일은 지우고, 이미 있던 파일은 건드리지 않는다.
3. **관리대장**
   - C-CODEX-02(`view_image`): L1 `view_image = false`, L2 금지 호출 거부(C6.14). 실제 `codex.exe` 0.162.1 L2가 2026-10-29 40회(C6.14-2), 2026-11-11 main `f525c8f` 전체 시험의 `test_real_codex_passes_l2`에서 통과했다. 상태를 조치·재검사 완료로 바꾼다.
   - C-CODEX-03(원격 모델 정보): `model_catalog_json` 고정(`multi_agent_version` 없음), L1 `code_mode`·`multi_agent` 끔, 같은 모델 정보로 L2. 같은 근거로 조치·재검사 완료다. "서버가 code mode를 강제하면 깨질 수 있음"은 조치 칸에 남은 위험으로 그대로 둔다.
   - 새 발견 행 C-INST-01(낮음)을 더한다.

## 시험

`tests/unit/test_install_codex.py`(24개, 네트워크 없이 합성 응답).

- 레지스트리 밖 처음 주소 6종 거부(http, 비슷한 호스트, 사용자 정보, 다른 포트, 잘못된 포트, 경로에만 이름)
- 리다이렉트: 같은 레지스트리는 따르고, 다른 호스트·http는 거부
- 크기: 상한 안 본문은 그대로 씀. 선언 없음·선언이 맞지만 본문이 넘침·선언이 큼 세 경우 모두 `CODEX_INSTALL_TOO_LARGE`이고 파일이 남지 않음. 이미 있던 파일은 보존
- 출력: 코드 모양이 아닌 글(경로, 소문자, 인자 둘)은 `CODEX_INSTALL_FAILED`. `except ... as` 블록 안에 `print` 호출이 없음(AST)
- 고치기 전 스크립트로 돌리면 새 시험 10개가 실패한다(리다이렉트·크기·출력·AST). 처음 주소 6종은 이전 접두어 검사로도 막혀 둘 다 통과한다.
