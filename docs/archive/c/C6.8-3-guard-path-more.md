## 관찰

1. **T29 재시도 사유:** 정책 변경으로 정지된 Task의 새 요청은 `TASK_NOT_RUNNING`이 아니라 `POLICY_CHANGED`로 거부된다. 정지 사유가 그대로 돌아온다.
2. **T29 하니스 주의:** `Run.create_task`는 조립 당시 Profile 버전으로 Task를 만든다. 정책을 바꾼 뒤 새 Task는 바뀐 버전으로 만들어야 하고, 아니면 `POLICY_CHANGED`로 거부된다(시험에서는 바뀐 설정으로 직접 만든다).
3. **T33 등급:** 미분류로 멈춘 Task는 실제로 읽은 기밀 등급도, 서버가 주장한 공개 등급도 반영하지 않는다. 결과가 공개되지 않고 그 Task는 더 실행하지 않으니 안전하다. 실제 C 파일 서버로 본 일치 쪽(#87 C 리뷰)과 합쳐 T33을 완료로 센다.
4. **S05 범위:** C6.9는 접근 규칙 판정기 예외였고, 이번은 정책 판정 자체다. 둘 다 그 요청만 거부하고 Guard 전체는 멈추지 않는다.
5. **T34와 C6.11:** 이 시험은 모드별 기대 결과를 한 번씩 확인한다. 모드별 10회 replay·일치율·과잉 제한은 C6.11 실험으로 남는다.
