## 우리 방식과 대조

- 지금 방식: 고정 Codex 0.162.1의 내장 ChatGPT 로그인(기기 코드, A109 브라우저 로그인)이다. 2026-10-29 실측한 `authUrl`의 `client_id`는 Codex 앱 값(`app_EMoamEEZ73f0CkXaXp7hrann`)이고, 로그인 화면에는 Codex 이름이 뜬다. `originator`만 `mcp_runtime_guard`다(C2.21 기록).
- 우리 앱이 다른 앱이나 OpenAI를 사칭하지는 않는다. 사용자는 Codex 공식 클라이언트로 Codex에 로그인한다.
- 다만 제3자 앱이 사용자의 ChatGPT 요금제를 쓰는 공식 경로는 앱 이름으로 등록한 OAuth다. 저장소는 비공개라 "오픈소스 파트너"에 해당하지 않고, 비공개 클라이언트는 선정된 경우만이다.
- API 키 로그인은 이 약관과 관계없다(기존 판정 그대로).
