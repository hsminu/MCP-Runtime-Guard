# B3.17 설정 불일치 서버의 시작 제외

2026-10-30 · B 담당

`startable_servers`는 기존 `URL_*` 이슈에 더해 정확히 `REG_SETTINGS_MISMATCH`인 서버도 제외한다. 선택된 설정과 다른 이슈 코드는 유지한다. 서버를 시작하지 않아도 A가 같은 편집을 다시 저장하고 `record_settings_change`가 Registry를 맞추면 이슈가 없어져 다음 시작에 포함된다.

실제 SQLite와 C `ServerRegistry`를 이용해 READ 등록을 SEND로 바꾼 뒤 이전 설정을 읽으면 불일치·시작 제외되고, 기존 READ 설정을 다시 저장하면 서버 연결 없이 이슈가 없어지고 시작 대상에 복귀함을 확인했다. 기존 B 시험의 불일치 서버 시작 기대는 새 결정에 맞게 고쳤다. A 조립과 `apply_settings` 연결은 [#99](https://github.com/hsminu/MCP-Runtime-Guard/pull/99) 기준으로 확인한다.
