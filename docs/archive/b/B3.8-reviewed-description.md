- `ToolSpec.reviewed_description: ReviewedDescription = ""`, repr 제외다. 기존 생성자는 새 인자가 없어도 동작하고 RegisteredServer·Profile 범위 Registry를 거쳐도 값을 유지한다.
- `ReviewedDescription`은 최대 2,000 Unicode code point 문자열이다. 빈 값·일반 Unicode·LF·TAB은 허용한다. None·숫자·bool을 문자열로 강제 변환하지 않는다.
- 제어/형식 문자·surrogate·Unicode 줄/문단 구분자는 거부한다. LF·TAB 이외의 제어 문자이므로 CR도 거부한다. 길이 초과를 자르거나 NFC·공백 정리로 조용히 바꾸지 않는다. frozen·model_copy 재검증을 유지한다.
- 이 필드는 사용자 검토 문구이므로 SCAN-01의 링크·HTML 어휘 거부 규칙은 강제하지 않는다. 입력·표시 화면은 원문을 일반 텍스트로 다뤄야 한다. 임의 길이·문자를 승인했다는 의미는 아니다.
- `Catalog.tool_views()`의 기존 메서드 서명은 그대로다. `ToolView.description`에 `tool.reviewed_description`만 넣고, 필드가 없던 옛 입력이나 빈 값은 빈 설명으로 둔다. 서버 원본·schema description·이름·Scanner summary로 자동 대체하지 않는다.
- ACTIVE·지원 종류·지문 일치 필터, 도구 순서와 닫힌 입력 schema는 유지한다. 설명이 있어도 PENDING·OTHER·지문 불일치 도구는 노출하지 않는다. 잘못 구성된 Registry 모델은 기존 CatalogConfigError 경계에서 원문 없이 거부한다.

## 검토 출처와 적용 범위

- 이 DTO는 검토 provenance를 암호학적으로 증명하지 않는다. **A의 명시적 사용자 검토 입력을 C가 저장한 값만** 이 필드에 넣어야 한다. 서버 `tools/list`에 같은 이름의 키가 있어도 자동 신뢰·복사하지 않는다.
- 원본 Tool dict의 JCS 지문 함수는 바꾸지 않았다. 사용자 검토 문구를 원본 Tool dict에 섞어 fingerprint를 계산하지 않는다. C는 원본과 검토 문구를 분리해 보관해야 한다.
- 입력 schema의 기존 description 같은 원본 metadata를 정화하거나 지우는 작업은 하지 않았다. 새 기능은 ToolView의 도구 설명 필드를 고르는 것이다.
- 검토 문구는 현재 Profile 설정 문서에 넣지 않으므로 그것만 바꾼 Registry 사본은 `policy_version` 계산을 바꾸지 않는다. Profile Registry가 문구를 보존하고, 문서와 policy_version이 그대로임을 확인했다.
- 실행 중 설명 편집의 Task·승인·Codex 도구 목록 갱신 의미는 아직 합의하지 않았다. ToolSpec의 전체 객체 비교에는 추가 필드도 들어간다. 기존 승인 해시 payload는 바꾸지 않았으며 저장/변경 명령과 세션 재등록까지 구현했다고 주장하지 않는다.
- 도구 지문이 바뀔 때 기존 검토 문구를 유지할지 비울지, 재검토 요구와 UI/세션 갱신은 A·C와 정해야 한다. B3.13에서 추적한다.

## 전달할 것과 미완료

- **A 요청**: 등록 화면의 검토된 설명 입력·일반 텍스트 표시·길이/문자 오류 안내를 연결한다. 빈 값을 서버 원본으로 자동 채우지 않는다. 사용자 검토 후 C 저장 입구에 전달한다. 제외한 UI 테스트의 한글 경로 PC 멈춤을 별도 확인한다.
- **C 요청**: 원본 metadata와 검토된 설명을 분리해 영속화하고 ToolSpec 복원 시 reviewed_description을 채운다. 원본 서버 값에서 검토 여부를 추론하지 않는다. 지문 변경·재검토·설명 변경 발행 의미를 A·B와 확인한다.
- **A·B·C 합의 필요**: 필드·기본값·2,000자·허용 문자와 변경 적용 의미. B3.13에서 추적한다. A 입력·C 저장·실제 Codex 도구 등록·독립 인수는 이 작업 범위 밖이며 확인 불가다.
- 현재 B 브랜치에 커밋하고 push·PR 생성은 하지 않는다. `Claude outputs/`는 추가·수정하지 않았다.
