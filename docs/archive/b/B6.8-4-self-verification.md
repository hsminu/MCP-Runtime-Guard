# B6.8 영속 순번·실패 감사 자체 검증

2026-10-30 · 기준 main `4d8c7a6` · **C 독립 확인 대신 B 자체 검증(사용자 결정 2026-10-30)**. 실제 SQLite와 자식 프로세스 강제 종료를 사용한 B 시험이며, C의 독립 wire·수신 계수를 주장하지 않는다. 제품 코드·C 시험·`docs/b-status.md`는 변경하지 않았다.

강제 종료 지점은 C의 #104 하니스 방식에 맞춰 실제 SQLite 연결의 SQL 실행 경계로 식별했다. 이 확인은 프로세스 강제 종료와 SQLite COMMIT의 결과이며 전원 차단 내구성까지 검증하지 않는다. 각 새 시험 파일을 세 차례 실행했다: 순번 6 passed씩 6.54·6.34·6.97초, 실패 감사 10 passed씩 4.41·4.91·4.57초.

복구 뒤 같은 Task가 이어서 배정받는 경로는 REC-04 설계상 없음(보류가 아니라 해당 없음). 근거는 [SEQ·REC 결정](B6.17-seq-rec-decisions.md)의 REC-03 옛 생애 보존·현재 run 소유 제한과 [복구·활성화 기록](B6.8-2b-recover-and-activate.md)의 이전 회차 Task 분리다. REC-04는 성공 복구 보고 범위를 정한다. 위 시험은 옛 계수 보존과 이전 Task 거부를 직접 확인한다.
