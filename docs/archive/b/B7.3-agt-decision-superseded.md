# B7.3 · AGT-01 검토를 사용자 결정으로 대체

## 한 일

- `docs/contracts.md`의 2026-10-15 AGT 제거 결정과 미결 요청 표의 AGT-01 상태를 대조했다.
- `docs/b-status.md`의 B7.3을 "10-15 AGT 제거 결정으로 대체"로 닫고, AGT-01–03 결정·회신 대기를 막힘 표에서 제거했다.
- 자체 접근 규칙 구현·동기 포트·reason code·기존 AGT 코드 제거는 B2.8–B2.11의 미완료 작업으로 분리했다. 코드와 공개 API는 바꾸지 않았다.

## 실제 검증

- 계약 문서와 개발문서 10.3절에서 자체 규칙의 범위와 B·A·C 담당을 확인했다.
- 현황 문서 구조 검사와 `git diff --check`를 실행해 통과했다. 기존 ID와 무관한 항목을 보존하고 B7.3의 종결 상태를 확인했다.
- 저장소 전체 검사 결과와 환경 제약은 [B7.10 기록](B7.10-contract-status-proposal.md#실제-검증)에 있다.

## 남은 한계

- 이번 종결은 AGT-01 검토 요청이 사용자 결정으로 대체됐다는 뜻이다. 접근 규칙 구현·연결·계수 검증을 완료한 것은 아니다.
- ACCESS-01·AGT-04의 `ports.py`·`domain/*` 변경은 3인 합의가 필요하다. A 연결·병합과 C 검증도 남아 있다.
