### 재시작·소유 관계가 없는 승인

메모리 snapshot·종결 중 관계·inflight가 모두 없으면 live 승인 행을 읽고
`APPROVAL_CONTEXT_LOST`로 실행을 거부한다. Task 소유자를 추측해 lock 없이
승인 행을 변경하거나 실행 권한을 복원하지 않는다. 그래서 시작 복구 전에는
DB 행이 PENDING/APPROVED로 남을 수 있다. 기존 재시작 단위 테스트도
실행 거부·소비 0·PENDING 유지로 갱신했다.
기술설계의 재시작 일괄 폐기(ADR-4/T11)는 **B6 시작 복구와 A 연결이 남은 작업**이다.
이번 보완을 시작 복구 완료로 표시하지 않는다.

dispatch는 메모리 Transport의 실제 호출 횟수로 확인한다. 실제 MCP wire·수신 부작용·
A 앱의 전체 연동이나 C 독립 인수를 수행한 것으로 표시하지 않는다.

이 변경은 사용자 요청 범위인 구현·테스트·**로컬 add까지** 공유 준비한다.
